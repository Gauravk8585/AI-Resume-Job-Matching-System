# AI Resume & Job Matching System

An AI-powered web application that analyzes resumes, extracts candidate information, and matches candidates with relevant job opportunities using Artificial Intelligence, Natural Language Processing (NLP), and Machine Learning.

## About the Project

The **AI Resume & Job Matching System** is designed to simplify the recruitment process by automatically analyzing resumes and identifying suitable job opportunities based on candidates' skills, qualifications, experience, and professional background.

The system evaluates resume content against job descriptions and generates matching scores to help candidates discover relevant career opportunities while helping recruiters identify suitable applicants.

## Key Features

- **Resume Upload:** Upload resumes in PDF format.
- **Resume Parsing:** Automatically extract skills, education, experience, and qualifications.
- **AI-Based Analysis:** Analyze resume content using NLP techniques.
- **Job Matching:** Match candidates with relevant job descriptions.
- **Match Percentage:** Generate compatibility scores for job recommendations.
- **Skill Gap Analysis:** Identify missing skills based on job requirements.
- **Job Recommendations:** Suggest suitable job roles based on candidate profiles.
- **User-Friendly Interface:** Simple and interactive web application.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript / React
- **Backend:** Python / Node.js
- **AI & Machine Learning:** NLP, Machine Learning

## How It Works

1. User uploads their resume.
2. The system extracts relevant information.
3. AI analyzes skills, education, and experience.
4. Job descriptions are compared with the candidate's profile.
5. The system calculates job compatibility scores.
6. Relevant job opportunities are recommended.

## Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/your-username/AI-Resume-Job-Matching-System.git
```

**2. Navigate to the project directory**

```bash
cd AI-Resume-Job-Matching-System
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

**5. Open in browser**

```text
http://localhost:5000
```
